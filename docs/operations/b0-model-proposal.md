## 请求约束

评估和摘要共用 ChatClient，固定请求 `enable_thinking: false`、JSON Object 输出，分别使用现有 400/1500 输出 token 限制。三个新候选默认开启思考；思考额外计入输出费用，且 `max_tokens` 只限制最终回答，因此不能依赖默认值。依据[深度思考文档](https://help.aliyun.com/zh/model-studio/deep-thinking)。

JSON Object 不保证业务字段符合 schema，仍需现有 Pydantic 校验和一次修复重试，见[结构化输出文档](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。新版回放缓存将非思考参数计入输入哈希；旧版依赖供应商默认模式的缓存不会被误用。

## 一轮费用估算

按设计的每事件输入约 1500、输出约 150 token 估算。先用训练集比较四个候选（4 × 120 = 480 个事件），固定模型和提示词后，仅对最终选定模型运行 30 条 holdout；留出结果不用于在四个模型之间继续挑选。

| 候选 | 120 条训练，输出 150 | 同输入、输出均到 400 |
|---|---:|---:|
| deepseek-v4.1-flash（忙时） | 0.5040 | 0.7440 |
| deepseek-v4-flash | 0.2160 | 0.2760 |
| qwen3.8-flash | 0.1926 | 0.2736 |
| qwen-plus | 0.1800 | 0.2400 |
| 四模型训练合计 | **1.0926** | **1.5336** |

最后 30 条按最贵候选估算分别增加 0.1260 / 0.1860 元，本轮合计约 **1.22 / 1.72 元**。这是固定输入假设下、不含重试的算术估计，不是实际账单或费用硬上限；实际输入长度、JSON 修复、网络重试与价格变化都会影响费用。摘要生成和全库 LLM 回放不在这 510 个事件中。

当前每次 replay CLI 的新增费用上限取 `llm.daily_cost_ceiling_cny=5`，多个进程不共享额度。四次训练加一次留出并不自动受合计 5 元限制；如果沿用默认值，五次进程各有独立的 5 元额度。真实样本审核完成后，应根据输入规模确定本轮总预算和各次额度，形成可复核的运行清单，再取得设计 §3.10 要求的付费调用确认。

## 真实样本的预算预留

已提取三周真实数据并生成 150 条待审核样本。离线按回放的首轮请求构造文本、使用现有代码的 `UTF-8 字节数 + 128` 作为输入 token 预留量，再按 400 输出 token 计算。按稳定 ID 预演的 120 条训练共预留 594,854 输入 token，30 条留出共 151,203；这是保守预留计算，未调用 tokenizer 或模型，不是实际用量。
